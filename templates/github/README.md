# GitHub templates

Copy into **sub-project** repos (`projects/<name>/`).

| File / folder | Destination |
|---------------|-------------|
| `ISSUE_TEMPLATE/` | `projects/<name>/.github/ISSUE_TEMPLATE/` |
| `PULL_REQUEST_TEMPLATE.md` | `projects/<name>/.github/PULL_REQUEST_TEMPLATE.md` or repo root |
| `workflows/*.example` | `projects/<name>/.github/workflows/` (rename; optional) |
| `dependabot.yml.example` | `projects/<name>/.github/dependabot.yml` |

See `.cursor/rules/github-issues.mdc`, `github-pr.mdc`, `git-branches.mdc`, and related skills.
