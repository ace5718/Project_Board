# Structure templates

Optional folder skeletons for new modules. Copy into sub-project repos and adjust naming.

| Template | Intended stack |
|---------|-----------------|
| `react-feature/` | React/Next/Vite feature module |
| `python-module/` | Python module package |

Principles:

- Follow existing repo structure first.
- Use templates only when structure is not yet established.
- Keep naming aligned with `project-structure` rule.
