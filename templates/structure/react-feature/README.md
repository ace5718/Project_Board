# React feature module skeleton

Rename this folder to your feature slug (e.g. `auth`, `billing`), then place under existing feature path.

Suggested layout:

```text
<feature>/
  components/
  hooks/
  lib/
  types.ts
  index.ts
```

Naming:

- Component files: `PascalCase.tsx`
- Other files/folders: `kebab-case`
